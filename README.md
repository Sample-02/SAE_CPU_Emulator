## Build project :
1. Open terminal
2. Go where you cloned project
3. cargo build

## Start project :
1. Open terminal
2. Go where you cloned project
3. Go /target/debug
4. ./livrable1 [OPTIONS] <BINARY_FILE>

==============
## Commandes
Help
./livrable1 -h
-------
Decode Binary File
./livrable1 yourfile.bin
